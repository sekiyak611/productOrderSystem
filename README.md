# 商品注文・料金計算システム

EC サイトの商品注文処理（商品割引・会員割引・キャンペーン割引・送料・支払）を行うコンソールアプリケーションです。

## 動作環境

- Java 21
- Gradle（同梱の Gradle Wrapper を使用）

## 実行方法

```bash
# ビルド
./gradlew bootJar

# 実行（起動後、支払方法の番号を入力する）
java -jar build/libs/productOrderSystem-0.0.1-SNAPSHOT.jar

# テスト
./gradlew test
```

Windows の場合は `gradlew.bat` を使用してください。Eclipse からは `ProductOrderSystemApplication` を Java アプリケーションとして実行できます。

注文内容（ノートPC×1、マウス×2、水×5、会員ランク SILVER）は `ProductOrderRunner` に固定で定義しています。

### 実行例

## 計算順序

1. 商品種別による割引（明細ごと）→ 小計
2. 会員割引
3. キャンペーン割引（会員割引後の金額に対して適用）
4. 送料（会員割引適用後の商品金額が 10,000 円以上なら無料、未満なら 500 円）

キャンペーン割引は 100,000 円以上が条件のため、キャンペーン適用によって送料の判定が変わることはありません。

## 端数処理のルール

- 金額の計算結果はすべて **1 円未満を切り捨て** ます。
- 商品種別割引は **明細金額（単価 × 個数）** に係数を掛けて、割引後の明細金額を求めます。
  - FOOD：明細金額 × 0.05（例：水 100 円 × 5 → 500 円 × 0.05 → 25 円）
  - ELECTRONICS（単価 50,000 円以上）：明細金額 × 0.1（例：ノートPC 100,000 円 × 1 → 10,000 円）
- ELECTRONICS の「50,000 円以上」の判定は **単価** で行います。
- 会員割引は商品種別割引後の小計に、キャンペーン割引は会員割引後の金額に割引率を掛けて、割引額を計算します。

## 主要クラスの責務

| クラス | 責務 |
|---|---|
| `ProductOrderRunner` | コンソールからの入力受付と結果出力 |
| `ProductOrderController` | 入力をサービスに渡す |
| `ProductOrderServiceImpl` | 料金計算（商品割引・会員割引・キャンペーン・送料）と注文結果メッセージの作成 |
| `ProductRepository` | 商品データの取得（疑似データ） |
| `EnumPaymentMethod` | 支払方法の定義と支払完了メッセージの作成 |
| `Campaign` / `LargeOrderCampaign` | キャンペーン割引の定義と、高額注文キャンペーン（100,000 円以上で 2% 割引）の実装 |

## 拡張時の変更箇所

- **キャンペーンの追加**：`Campaign` を実装したクラスを `@Component` として追加するだけで、既存コードの変更は不要です（サービスには Spring がすべての `Campaign` Bean を注入します）。
- **支払方法の追加**：`EnumPaymentMethod` に定数（ID・名称・メッセージ書式）を追加します。
- **商品種別・会員ランクの追加**：各 enum に定数を追加し、`ProductOrderServiceImpl` の割引率の `switch` に分岐を追加します。
